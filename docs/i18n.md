# Internationalization (i18n)

Supported locales: **`es`** (default) and **`en`**.

## Approach

- **No URL prefix** — invite/public permalinks stay `/i/[slug]` and `/c/[slug]`.
- Locale lives in cookie `ow_locale`.
- First visit: cookie set from `Accept-Language` (falls back to `es`).
- Switcher on home, auth, dashboard nav, invite, public campaign, and design lab.

## Code

| Path | Role |
|------|------|
| [`src/i18n/config.ts`](../src/i18n/config.ts) | Locales + cookie name |
| [`src/i18n/dictionaries/es.ts`](../src/i18n/dictionaries/es.ts) | Spanish copy |
| [`src/i18n/dictionaries/en.ts`](../src/i18n/dictionaries/en.ts) | English copy |
| [`src/i18n/get-dictionary.ts`](../src/i18n/get-dictionary.ts) | Server helpers |
| [`src/i18n/set-locale.ts`](../src/i18n/set-locale.ts) | Server action to set cookie |
| [`src/components/locale-switcher.tsx`](../src/components/locale-switcher.tsx) | ES / EN control |

`html lang` follows the active locale ([`src/app/layout.tsx`](../src/app/layout.tsx)).

## Adding strings

1. Extend `Dictionary` in [`src/i18n/types.ts`](../src/i18n/types.ts).
2. Add keys to both `es.ts` and `en.ts`.
3. Read via `await getDictionary()` in Server Components, or pass labels into Client Components.
